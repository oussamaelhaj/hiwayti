Écosystème des Rôles

Touriste

Découvre, réserve et explore l'authenticité marocaine avec des recommandations IA.

Artisan / Prestataire

Gère ses activités, ses réservations et suit ses revenus via un dashboard dédié.

Commune

Supervise l'impact économique et valide les prestataires locaux.

Admin

Gestion globale de la plateforme, modération et statistiques avancées.

Architecture du Projet

Application Mobile (Expo / React Native)
Firebase (Auth, Firestore, Storage, Functions)
AI Engine (Recommandations & Analyse)
React Native Frontend
Firebase NoSQL Backend
Multi-Rôles Architecture
